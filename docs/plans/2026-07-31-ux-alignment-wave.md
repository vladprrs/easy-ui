## Сквозные решения

**S1. Два уровня навигации выражаются разными средствами.** Сегмент хрома — *место*
(«Плеер · Сценарии · Редактор»); режим внутри разбора («Сценарии/Дорожки») — сегмент
в канве CJM над счётчиками. Аббревиатура «CJM» уходит из всех видимых подписей,
`document.title` и aria — включая `strings/cjm.ts`. Маршрут `/p/:id/cjm` остаётся.

**S2. Один акцент на экран.** Курсив+красный — ровно один фрагмент. «Не готово»
кодируется `rgba(45,8,58,.25)`, а не вторым красным. Токен `--color-pay-invalid`
остаётся, меняются места применения.

**S3. Один код одного факта, но факт не теряется.** Верификация ребра сегодня
кодируется цветом + штрихом + глифом «!». Остаётся цвет + форма наконечника:
подтверждён — залитый зелёный треугольник; динамический — полый зелёный;
не найден — залитый `rgba(45,8,58,.25)`. Легенда одна, видна в обоих режимах CJM.

**S4. Общие примитивы вместо копий** (волна W0, все файлы новые):
- `src/app/Modal.tsx` — бекдроп `bg-pay-deep/55`, панель `rounded-panel bg-white p-7`,
  ширина 440–460, `headingDialog`, Esc, focus-trap, возврат фокуса, `aria-labelledby`;
  плюс `ConfirmModal` для деструктива. **Не применяется** к `ScreenLightbox` и `PresentHud`.
- `src/app/states.tsx` — `Skeleton` / `ErrorState` / `EmptyState` / `BrandCircles`
  (переезжают из `GalleryStates`, которые становятся тонкой обёрткой).
- `src/app/Menu.tsx` — `role="menu"`, ↑↓ + Enter + Esc, возврат фокуса, сабменю.
  Общий для меню карточки галереи и нового «···» плеера.
- `src/app/Toggle.tsx` — трек 38×22 красный, кноб белый 16.
- `src/app/SelectPill.tsx` — `appearance-none` + текстовая каретка `▾` красная 2×18.

**S5. Набор глифов заморожен:** `▾ ▸ ← → ✕ ···`. `×`(U+00D7), `⋯`(U+22EF), `›`, `•••`
заменяются. Признак раскрытия — смена глифа `▸`→`▾`, не вращение.

**S6. Деструктив = `ConfirmModal`** с текстом последствия. Второй клик на кнопке —
только для локально обратимого (удалить проверку, удалить регион), с окном ≥1.5 с
и сменой подписи. `window.confirm` убирается везде.
